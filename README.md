# Бит-Бот

MaxBot — бот для платформы `max.ru` / Max API.
Нужен для автоматизации работы с клиентами.

Он умеет:
- регистрировать пользователей по ссылкам `?start=trial`, `?start=kid`, `?start=parent`
- сохранять данные в SQLite
- отправлять напоминания о пробных занятиях и уроках
- отслеживать активность в рабочих группах
- делиться полезными материалами: загружать файл `checklist.pdf` и использовать его как вложение

## Структура проекта

- `src/main.py` — точка входа
- `src/core/bot.py` — инициализация бота `maxapi`
- `src/handlers/` — обработчики событий и сценарии
- `src/services/` — бизнес-логика, напоминания, загрузка файлов, AmoCRM
- `src/db/` — база данных SQLite, репозитории и схема
- `src/keyboards/` — клавиатуры и кнопки для бота
- `src/config.py` — конфигурация путей и констант
- `src/texts.py` — набор единичных и сценарных текстов, которыми бот общается с пользователем 
- `src/env.py` — токены и настройки окружения (в идеале сделать через дотенв)
- `db/schema.sql` — SQL-схема базы данных

## Требования

- Python 3.10+
- Рекомендуется Python 3.11

## Зависимости

- `maxapi`
- `aiosqlite`
- `requests`

## Установка

1. Клонируйте репозиторий.
2. Перейдите в каталог проекта.
3. Установите зависимости через венв, поэтри или подобное :

pip install -r requirements.txt

## Настройка

В src/env.py укажите:

TOKEN — токен бота
ACCESS_TOKEN — токен AmoCRM
id_bot — идентификатор бота для dev/prod

В src/config.py проверьте пути к файлам:

data/users.json
data/checklist.pdf
users.db
db/schema.sql

## Запуск
python src/main.py

## Что происходит при запуске

загружается checklist.pdf
инициализируется база данных
запускается reminder_worker
запускается polling бота

## Работа с ботом

Поддерживаются следующие стартовые payload:

?start=trial — пробное занятие
?start=kid — сценарий для ребёнка
?start=parent — сценарий для родителя
?start=lead — статус «не заплатил»
?start=admin — админский режим
База данных

Бот использует SQLite.
Схема базы описана в db/schema.sql.

## Дополнительно для разработчика
- amoservice.py делает запросы в AmoCRM, но пока используется не во всех местах
- database.py создаёт и открывает SQLite-базу
- данные о кураторах и учителях константные и находятся в конфиге в маиисах с соответствующим названием
- при пуше на сервер стоит заранее сделать бекаб базы данных к себе на пк командой 
scp root@87.228.102.87:/root/botMax/users.db .
где 
87.228.102.87 - ип сервера 
точка в конце означает, что копирование произойдёт в репозиторий указаный в консоли
- после pull на сервере, стоит проверить файл env.py
